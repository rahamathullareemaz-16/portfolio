Embedded + AI

Intelligent Adaptive Real-Time ECG Monitoring

Problem

Cardiovascular diseases require continuous monitoring, but traditional embedded ECG systems fail under high CPU load, causing missed deadlines and unreliable performance.

Solution

Developed an intelligent ECG monitoring system using Raspberry Pi and biomedical sensors (AD8232, MAX30102, DS18B20) integrated with predictive CPU control and AI analytics.

Implementation

Used POSIX multi-threading with SCHED_FIFO scheduling, predictive CPU trend analysis, adaptive gain control, and medical-aware prioritization.

Outcome

Achieved stable CPU utilization, reduced deadline misses, real-time visualization, and reliable detection of abnormal cardiac conditions.
