Intelligent Adaptive Real-Time ECG Monitoring

Problem

Cardiovascular diseases require continuous monitoring, but traditional ECG systems rely on static scheduling and fail under high CPU load, leading to missed deadlines and unreliable monitoring.

Solution

Developed an intelligent real-time ECG monitoring system using Raspberry Pi and biomedical sensors (AD8232, MAX30102, DS18B20). Integrated predictive CPU control and AI-based health analytics for reliable operation.

Implementation

Implemented multi-threading using POSIX threads with SCHED_FIFO scheduling. Designed predictive CPU trend analysis, adaptive gain control, and medical-aware priority scheduling to ensure real-time performance.

Outcome

Achieved stable CPU utilization, reduced deadline misses, and ensured uninterrupted life-critical ECG processing with real-time visualization and intelligent alert generation.

Smart Rain & Heat Response System

Problem

Manual operation of windows and cooling systems leads to inconvenience, energy wastage, and damage during unexpected rainfall.

Solution

Designed an automated Arduino-based system to monitor rain and temperature and respond intelligently to environmental changes.

Implementation

Integrated rain sensor, DHT11 temperature sensor, servo motor for window control, and relay module for cooler activation. Used microcontroller logic for real-time decision making.

Outcome

Improved comfort, safety, and energy efficiency with fully automated system and reliable fault handling using watchdog timer.

Smart Customer Support Chatbot

Problem

Traditional customer support systems struggle to handle large volumes of queries efficiently, resulting in delays and poor user experience.

Solution

Developed an AI-powered chatbot combining ML-based intent recognition with GPT-based response generation to provide intelligent and flexible interactions.

Implementation

Built using HTML/CSS frontend, Flask backend, NLP (NLTK), and OpenAI integration. Implemented sentiment-aware responses and conversational flow handling.

Outcome

Delivered fast, accurate, and scalable support system with improved user satisfaction and reduced human workload.
